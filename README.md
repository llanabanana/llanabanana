## Projects

### [mrs-taxi-app](https://github.com/llanabanana/mrs-taxi-app)
Full-stack ride-sharing platform developed in a team of 3 across five concurrent university courses (Server-side, Client-side, Mobile Apps, Software Testing, Methodologies). Spring Boot REST API, Angular web app, and native Android app with real-time tracking, driver matching, notifications, and ride management. Two semesters of Scrum sprints, pull requests, code reviews, and CI. This was the most comprehensive project of my studies -- it taught me how real teams ship software.

### [siit-ib-projekat-tim-50](https://github.com/llanabanana/siit-ib-projekat-tim-50) -- PKI Certificate Platform
Team project (3 people): a PKI certificate management platform built with Spring Boot and Angular -- certificate issuance, revocation/CRL generation, master key rotation, and two-factor authentication. My part: the certificate issuance service (with validation), certificate revocation and CRL generation, signature chain verification, and the admin panel for CA user registration/activation with email notifications.

### [distributed-sensor-system](https://github.com/llanabanana/distributed-sensor-system)
Team project (3 people): a fault-tolerant distributed system for industrial sensor monitoring, split into command/query microservices (Ingestion, Consensus, Notification), with encrypted sensor data and Kubernetes deployment. My part: the initial microservices architecture and the IngestionService (validating and persisting incoming sensor readings), plus alarm detection with P1/P2/P3 priority levels and a watchdog service for sensor fault tolerance.

### [medallion-data-platform](https://github.com/llanabanana/medallion-data-platform)
Cloud data platform on AWS CDK (Python) implementing the Medallion architecture (Bronze/Silver/Gold). Ingests data from the Hacker News and Twitter APIs, and delivers analytics through PostgreSQL and Apache Superset dashboards. Team project for a Cloud Computing course.

### [webscraper-cpp](https://github.com/llanabanana/webscraper-cpp)
A concurrent web scraper in C++ using Intel TBB for parallelism and libcurl for HTTP. Custom HTML parser with regex-based extraction. Scrapes, parses, and analyzes book data across paginated pages.
